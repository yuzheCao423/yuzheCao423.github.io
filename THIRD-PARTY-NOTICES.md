# Template sources and notices

This homepage adapts the AcademicPages / Minimal Mistakes presentation used by Zonghe Shao's public academic homepage.

- Reference site: https://zhshao17.github.io/
- Reference source: https://github.com/zhshao17/zhshao17.github.io
- AcademicPages: https://github.com/academicpages/academicpages.github.io
- Minimal Mistakes: https://github.com/mmistakes/minimal-mistakes

`assets/css/academicpages.css` is the core template portion of the reference site's publicly served `assets/css/main.css`, retrieved on 2026-11-03. The unused appended Font Awesome icon/font distribution has been omitted. This package uses inline SVG interface icons and contains no third-party webfonts. The MIT notice from the reference repository is retained in `LICENSE`.

The HTML is adapted into a buildless static page, with original text, revised information order, a responsive layout overlay in `assets/css/custom.css`, and a small local script for navigation, theme switching and enlarged model figures. This package does not use the Jekyll runtime. The reference author's portrait, research biography and unrelated papers are not included.
